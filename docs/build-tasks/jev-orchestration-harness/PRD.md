## Success and acceptance

The [PRD success metrics](../../PRD-Jev-Orchestration-Harness.md#6-success-metrics) and [PRS CLI and verification contract](../../PRS-Jev-Orchestration-Harness.md#6-surface--view-specifications) govern acceptance. A fixture result proves plumbing; a pinned model's non-fixture local response proves local inference; mapped-device and server evidence plus that response is needed for an Intel Arc Pro B70 GPU claim. No coding-quality or Jev-routing superiority claim follows from a smoke run.

## Risks

The [PRD risks and open questions](../../PRD-Jev-Orchestration-Harness.md#8-risks--open-questions) remain canonical. The [plan](implementation_plan.md) maps implementation work and negative checks to those risks. An unavailable OVMS package, insufficient memory, or failure to load a model is an explicit failed dependency, never an occasion to record a fixture or CPU result as a GPU success.
